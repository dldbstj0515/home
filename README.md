# CareerFit — AI 기반 대학생 취업 지원 프로그램

사용자가 입력한 역량 정보와 목표 기업·직무의 채용공고를 비교해 **지원 조건 충족도(안정·소신·위험)** 를 분석하고, 부족한 역량과 **맞춤형 취업 준비 로드맵**을 제공하는 모바일 웹 프로토타입입니다.

이 문서는 다음 두 가지를 정리합니다.

1. `index.html`(와이어프레임) 버전별 변경이력
2. PRD 버전별 내용과 버전 간 차이

---

### v0.5 — 동작하는 프로토타입 (이전: v0.4)

정적 HTML 한 파일에서 `index.html` + `css/style.css` + `js/main.js` 구조로 분리되었고, 입력값에 따라 결과가 달라집니다.

**추가**

- 서비스명 **"커리어핏"** 과 SVG 아이콘 세트 적용
- **홈**: 진행 단계 표시(역량 입력 → 기업 선택 → 결과 확인), 상태에 따라 바뀌는 "다음 할 일" 버튼, 메뉴 타일 4개
- **역량 입력 폼 구현**: 학력(선택), 학점(0~4.5), 공인영어(TOEIC 0~990), 보유 기술(쉼표 구분), 자격증(계열별 목록에서 복수 선택). 학력·영어는 필수, 학점은 비워도 진행하며 입력 오류 메시지 표시
- **기업별 채용 조건 데이터**: 삼성전자(반도체 엔지니어)·네이버(서비스 기획)·카카오(백엔드 개발자)의 필수/우대 조건 내장, 기업 검색, 확인일 표기(예시)
- **충족 여부 자동 판정**: 조건별 충족(✓)·미충족(✗)·입력 없음(비교 제외)
- **충족도 3단계 자동 판정**: 필수 미충족이 있으면 위험, 필수를 모두 충족하고 우대를 하나 이상 충족하면 안정, 그 외 소신 (화면에 시연용 임시 규칙이라고 안내)
- 결과 화면에 충족도 미터와 "부족한 역량과 보완 방향" 카드, 출처 확인·준비 계획 보기 버튼
- **로드맵 자동 생성**: 미충족 조건과 포트폴리오 제작을 과제로 만들고, 주당 준비 시간(5·10·20시간)과 목표 지원 시점(3·6·12개월 후) 선택에 따라 예상 소요 개월 계산 및 목표 시점 충족 여부 안내
- 과제 체크로 완료 표시, 진행률 자동 계산
- 마이페이지의 저장한 분석 결과(기업과 충족도 단계), 정보 출처 항목, 기업별 확인일이 표시되는 정보 출처 화면

**변경**

- 서비스명 "취업 지원 서비스" → "커리어핏"
- 문자 기호 아이콘 → SVG 아이콘
- 홈의 "추천 기업" → "분석할 수 있는 기업"
- 결과 화면이 고정 예시("소신") → 입력에 따라 달라지는 결과

**삭제**

- 홈의 빠른 메뉴 목록과 "내 취업 경쟁력 확인하기" 카드(진행 단계·메뉴 타일로 대체)
- 고정값이던 진행률 45%와 정적 로드맵 3단계 예시
- 로드맵의 "자격증 취득 계획 / 포트폴리오 제작 계획" 이동 행(과제 목록 안으로 통합)
- "분석 결과 예시" 등 예시 라벨

## 2. PRD 버전

원문: `md/PRD ver 0.1.md` · `md/PRD ver 0.2.md`

### PRD v0.1 — 제품 범위와 기능 정의

**제품 목적**: 사용자 역량과 실제 채용공고를 비교해 지원 조건 충족도를 분석하고, 부족한 역량과 취업 준비 로드맵을 제공한다.

**핵심 가치**: 채용 조건 분석 · 지원 전략 수립(안정·소신·위험) · 역량 보완 · 취업 준비 계획 · 정보 검증(출처 제공)

**주요 사용자**: 취업을 준비하는 대학생 (요구사항 5개 정의)

**이용 흐름(8단계)**: 역량 입력 → 목표 기업·직무 선택 → 조건 분석 → 충족도 확인 → 부족 역량 확인 → 로드맵 확인 → 자격증·포트폴리오 계획 확인 → 근거·출처 확인

**기능 요구사항 (MoSCoW)**

| 우선순위 | ID | 기능 |
| --- | --- | --- |
| Must | F-01 | 사용자 역량 정보 입력 |
| Must | F-02 | 목표 기업·직무 선택 |
| Must | F-03 | 기업별 채용 조건 비교 |
| Must | F-04 | 지원 조건 충족도 3단계 분류 |
| Must | F-05 | 부족한 역량 분석 및 추천 |
| Must | F-06 | 단계별 취업 준비 일정 |
| Must | F-07 | 채용 조건·자격증 정보 출처 표시 |
| Should | F-08 | 포트폴리오 제작 로드맵 |
| Should | F-09 | 자격증 취득 준비 로드맵 |
| Should | F-10 | 준비 계획 수정 및 재추천 |
| Should | F-11 | 준비 진행 상황 체크 |
| Could | F-12 | 기업별 결과 비교 및 저장 |

**제외 범위(Won't)**: 이력서·자기소개서 작성 및 면접 평가 / 합격 확률 예측·보장 / 전체 기업의 실시간 채용정보 자동 수집 / 외부 서비스 연동·자동 알림

**화면 구조(9개)**: S-01 역량 입력 · S-02 기업·직무 선택 · S-03 조건 분석 · S-04 충족도 확인 · S-05 부족한 역량 · S-06 맞춤형 로드맵 · S-07 자격증 계획 · S-08 포트폴리오 계획 · S-09 추천 근거·출처

### PRD v0.2 — 판정 기준과 데이터 범위 확정

**제품명**: AI 기반 대학생 취업 지원 프로그램 **(CareerFit AI)**

**입력 데이터 분류**

| 구분 | 항목 | 필수 여부 |
| --- | --- | --- |
| 기본 역량 | 학교/전공, 공인영어 점수, 자격증, 기술 스택 | 필수 |
| 선택 역량 | 학점(GPA), 수상 경력, 프로젝트 경험 수 | 선택 (비워도 분석 진행) |
| 목표 조건 | 목표 직무, 목표 기업, 목표 지원 시점(월), 주당 준비 가능 시간 | 필수 |

**3단계 판정 기준** (합격 확률이 아닌 채용 조건 충족도)

| 단계 | 기준 |
| --- | --- |
| 안정 | 필수 조건 100% 충족 + 우대 조건 50% 이상 충족 |
| 소신 | 필수 조건 100% 충족 + 우대 조건 50% 미만 충족 |
| 위험 | 필수 조건 중 1개 이상 미충족 |

**로드맵 예상 기간**: 총 필요 주수 = Σ(부족 역량 항목별 표준 소요 시간) ÷ (주당 준비 가능 시간 ÷ 10)
예) 자격증 40시간 + 포트폴리오 60시간 = 100시간, 주당 10시간 → **10주**

**데이터 수집·시범 운영 범위**

- 대상 직무 4개: 프론트엔드 개발자, 백엔드 개발자, UI/UX 디자이너, 서비스 기획자
- 대상 기업: 네이버·카카오·쿠팡 등 10개 표본 기업의 공고를 사전 구축
- 공고 텍스트를 JSON으로 구조화해 DB에 보관, 결과 화면 하단에 **[출처 링크]** 와 **[데이터 확인 날짜]** 표기
