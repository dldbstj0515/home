# PRD: AI 기반 대학생 취업 지원 프로그램 (v0.2)

## 1. 제품 개요
### 1.1 제품명
AI 기반 대학생 취업 지원 프로그램 (CareerFit AI)

### 1.2 제품 목적
사용자가 입력한 역량 정보와 목표 기업·직무의 실제 채용공고 데이터를 비교 분석하여 지원 조건 충족도(안정/소신/위험)를 판단하고, 부족한 역량을 채우기 위한 주차별/월별 맞춤형 취업 준비 로드맵을 제공한다.

### 1.3 핵심 가치
- **채용 조건 비교:** 실제 공고의 필수/우대 조건과 사용자 역량 간 일치도 자동 산출
- **지원 전략 수립:** 충족 비율(%) 기반 3단계 판정(안정·소신·위험) 및 명확한 근거 제시
- **역량 보완 로드맵:** 자격증, 영어 점수, 포트폴리오의 우선순위 설정 및 실행 계획 제공
- **출처 투명성:** AI 판단의 근거가 된 원문 공고 링크 및 데이터 수집 시점 명시

## 3. 핵심 세부 판정 로직 (v0.2 추가 확정)

### 3.1 안정 · 소신 · 위험 3단계 판정 기준
*본 서비스는 합격 확률이 아닌 **'채용 조건 충족도'**만을 산출함을 명시함.*

- **안정 (Safe):** 필수 조건 100% 충족 + 우대 조건 50% 이상 충족
- **소신 (Moderate):** 필수 조건 100% 충족 + 우대 조건 50% 미만 충족
- **위험 (Risk):** 필수 조건 중 1개 이상 미충족

### 3.2 로드맵 예상 기간 산정 로직
$$\text{총 필요 주수} = \frac{\sum (\text{부족 역량 항목별 표준 소요 시간})}{(\text{주당 준비 가능 시간} / 10)}$$
* 예시: 자격증(40시간) + 포트폴리오(60시간) = 총 100시간 / 주당 10시간 = **10주 로드맵**

## 4. 데이터 수집 및 시범 운영 범위 (v0.2 확장)

### 4.1 타겟 직무 및 대상 기업
- **대상 직무:** 프론트엔드 개발자, 백엔드 개발자, UI/UX 디자이너, 서비스 기획자 (총 4개 분야)
- **대상 기업:** 주요 IT/네이버·카카오·쿠팡 등 10개 표본 기업 공고 데이터 사전 구축

### 4.2 데이터 파이프라인
- 타겟 기업의 실제 공고 텍스트를 구조화(JSON)하여 DB에 보관
- 모든 결과 화면 하단에 **[출처 링크]** 및 **[데이터 확인 날짜]** (예: 2026.11.01 기준) 표기

## 5. 화면 구조 통합안 (S-01 ~ S-09)

기존 v0.1의 9개 화면을 사용자 편의성을 위해 **4개의 메인 화면 흐름**으로 통합 구성한다.

```text
[View 1] 역량 입력 및 목표 설정 (S-01, S-02)
   └── 필수 입력폼, 목표 직무/기업 선택 UI

[View 2] 분석 및 충족도 결과 (S-03, S-04, S-05, S-09)
   └── 3단계 라벨 카드, 필수/우대 충족 그래프, 출처 원문 팝업

[View 3] 맞춤형 로드맵 (S-06, S-07, S-08)
   └── 주차별 실행 타임라인, 자격증/포트폴리오 가이드

[View 4] 준비 상황 대시보드 (F-11)
   └── 체크리스트 형태의 진행률(완료/진행중) 관리 UI
